# 先选适合自己的方案

你不需要先学懂 VPS、协议或代理术语。启动 Agent 后，它会先问几个日常问题，再去查当天的价格、地区和产品限制，最后给你一个主方案和一个备选方案。

## 四个看得懂的样例

| 你更像哪种人 | 一个具体例子 | Agent 通常会先查什么 |
| --- | --- | --- |
| 想先省钱试试 | 只有自己用，预算每月 3–15 美元，能接受偶尔换机房 | 一台低价海外服务器直接使用，先测你所在网络的延迟和丢包 |
| 更在意少断线 | 每月能花 10–35 美元，希望入口线路稳定 | 日本或其他亚洲服务器，比较不同线路后选择一台 |
| 必须显示某个国家 | 需要长期使用美国 IP，预算还能多出 3–20 美元/月 | 亚洲服务器再加一个固定的美国网络出口，先单独验证出口 |
| 不能接受单点故障 | 工作或长期使用，愿意维护两台机器 | 一台主服务器加一台备用服务器；Agent 会说明额外成本和切换方法 |

这些是帮助你理解的样例，不代表保证的价格或速度。Agent 会按当天页面和你的网络重新核对。

## Agent 会按这个顺序问你

| Agent 的问题 | 你可以怎么回答 | 它用来判断什么 |
| --- | --- | --- |
| 每月最多愿意花多少钱？ | “10 美元以内”“20 美元左右”“价格不是第一位” | 先排除超预算方案，并计算续费后的月均成本 |
| 你最怕什么？ | “不能经常断”“偶尔慢可以”“某个网站打不开最麻烦” | 把稳定、速度、可用性排出优先级 |
| 你平时做什么？ | “网页和文档”“视频会议”“游戏”“下载大文件” | 判断是否需要更低延迟、更高带宽或 UDP |
| 你希望网站看到哪个国家？ | “无所谓”“日本”“美国，而且最好长期不变” | 判断是否需要额外的固定出口 |
| 你用哪些设备？ | “Mac 和 iPhone”“Windows”“还有 Android” | 确认客户端和配置范围 |
| 你愿意自己维护几台机器？ | “只想维护一台”“两台也可以” | 决定是否提供备用节点或双 VPS |

你只需用自己的话回答。说不清时可以回答“我不知道”，Agent 应该解释这个问题再继续。

## Agent 调查后必须告诉你

1. 推荐哪条路径，以及用一句话解释原因。
2. 一次购买要付多少钱，续费多少钱，折算后每月多少。
3. 从哪些官网查到的，页面核验日期是什么。
4. 预计能解决什么，仍可能遇到什么问题。
5. 备选方案是什么，多花多少钱或少得到什么。
6. 你需要亲自完成哪些动作：注册、付款、验证码、密码输入和最终设备测试。

你确认方案后，Agent 才进入购买和部署步骤。
