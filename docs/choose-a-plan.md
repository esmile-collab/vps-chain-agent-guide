# 先选网络方案

先回答 Agent 的问题，再购买。Agent 会根据答案给出一个主方案和一个可回退方案。

## 四种常用路径

| 路径 | 适合谁 | 优点 | 代价和限制 |
| --- | --- | --- | --- |
| 一台 VPS 直连 | 预算有限、主要看稳定和速度 | 便宜、故障点少、维护简单 | 出口是机房 IP，地区和平台接受度取决于 VPS |
| 亚洲 VPS → 固定美国 SOCKS5/ISP | 需要固定美国出口、入口希望靠近自己 | 入口和出口可分别更换；出口 IP 稳定 | 多一层故障和延迟；出口供应商条款要单独确认 |
| 入口 VPS → 出口 VPS | 不想依赖代理供应商，想自己掌控两端 | IP、系统和日志都由自己控制 | 两台机器都要付费和维护；美国 VPS 仍是机房 IP |
| 主入口 + 备用入口 | 把“单点故障”降下来 | 一个入口故障时可切换 | 成本和维护量增加，备用节点也要定期测试 |

“家宽节点”常见的实际产品是静态 ISP/静态住宅代理。个人使用通常只需要一个固定、带认证的 SOCKS5；轮换住宅池、共享池和免费代理会增加不稳定与封禁风险。

## Agent 必问的问题

1. 你所在的国家/地区和主要网络运营商是什么？这决定入口机房的测试重点。
2. 你要访问的服务更看重速度、固定国家 IP、低延迟，还是多设备同时使用？只能先选最重要的两项。
3. 需要哪个国家的出口 IP？是否必须长期保持同一个 IP？
4. 每月预算上限是多少？能否接受按年付和自动续费？
5. 你有几台设备，是否需要 Windows、macOS、iPhone 或 Android？
6. 是否需要 UDP/游戏/视频会议？很多 SOCKS5 产品只保证 TCP。
7. 你愿意维护几台服务器？不愿意维护时，Agent 应优先推荐一台 VPS 直连。

## 选择规则

- 预算低于 15 美元/月：先做一台 VPS 直连测试，确认线路满足需求后再加出口。
- 需要固定美国 IP：先验证静态出口的 ASN、是否固定、是否支持 SOCKS5，再决定是否加链路。
- 入口线路差：换入口地区或供应商，单纯更换出口无法修复入口丢包。
- 只有某个网站或应用需要美国 IP：优先做分流，避免所有流量都经过出口。
- 需要所有流量走链路：明确告知用户 DNS、IPv6、UDP 和速度都会成为验收项。

## 付款前的确认句

Agent 必须把“供应商、产品名、地区、账期、一次性金额、续费金额、流量、退款、到期日”列出来，用户确认后才付款。页面上没有写清的字段标为未知，不猜测。
