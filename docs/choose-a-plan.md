# Agent 会怎么帮你选

你不用先选服务器、国家或技术方案。先把自己的情况讲清楚，Agent 负责把你的日常回答翻译成购买条件。

## 它会先问六个简单问题

### 1. 你用哪些设备？

可以回答：“一台 Windows 电脑和一台安卓手机”“Mac、iPhone 和 iPad”。

Agent 用这个答案确认最后要装几个客户端。手机只负责连接，第一次部署通常要在 Mac 或 Windows 电脑上完成。

### 2. 你现在最烦的是什么？

可以直接选最像的一句：

- 经常断，重新连接很麻烦。
- 晚上明显变慢。
- 某个网站或软件经常打不开。
- 工作账号希望长期显示同一个国家。
- 现在太贵，想降低费用。
- 我只是想少和陌生人共用。

Agent 会把最重要的问题排在第一位。你说“稳定最重要”时，它就不能只推荐最便宜的产品。

### 3. 你平时拿它做什么？

回答日常用途即可，例如网页、聊天、看视频、下载大文件、视频会议或游戏。

视频会议和游戏更怕延迟和突然断线；下载大文件更在意流量和速度。你不用判断这些指标，Agent 会据此检查。

### 4. 你愿意花多少钱？

最好给两个数字：

- 平均每月最多能接受多少；
- 第一次付款最多能接受多少。

例如：“平均每月 150 元以内，第一次最多付 500 元。”很多服务器按季度或年度收费，只说月预算容易在结账时超出承受范围。

如果完全没概念，就说：“先给我最低能用和比较省心两个档位。”Agent 应先查当天价格，再让你缩小预算。

### 5. 有没有必须显示的国家？

如果你只是上网页、看视频，可以回答“没有”。

如果某个长期使用的工作服务、商店或账号明确要求美国、日本等地区，就把服务名称和要求告诉 Agent。Agent 会判断它是否需要额外的固定当地地址。

拿不准时回答“不知道”。Agent 应继续问：

- 这个服务有没有明确提示国家不符合？
- 你是否需要长期登录同一个账号？
- 地址偶尔变化会不会影响工作？

这三个问题仍回答不出来时，先从更简单、费用更低的方案开始测试，避免提前购买用不上的服务。

### 6. 出问题时你能接受什么？

可以回答：“偶尔让 Agent 修一下可以”“工作不能中断，希望有备用”“只想维护一台，坏了再处理”。

备用方案会增加费用和续费事项。Agent 要把多花的钱和减少的中断风险一起说清楚。

## 三个生活化样例

### 样例 A：想先摆脱公共节点

```text
我用 Mac 和 iPhone，主要看网页和视频。
最烦的是晚上经常断。
平均每月最多 100 元，第一次最多付 300 元。
没有必须显示的国家。
```

Agent 通常会先查一台靠近亚洲、能单独使用的海外服务器，并确认它是否支持短周期购买。先买一份、先实测，减少一上来买很多服务的浪费。

### 样例 B：工作时不能频繁中断

```text
我用 Windows，天天开视频会议。
稳定比便宜更重要，每月可以到 250 元。
国家无所谓，但坏了要能尽快恢复。
```

Agent 会更看重从你所在网络连过去的质量、服务商故障记录、恢复控制台和备用方式。最低价不会自动成为推荐项。

### 样例 C：长期使用美国服务

```text
我用 Mac 和 iPhone，需要长期登录一个美国区工作服务。
我希望它看到的位置尽量不变。
平均每月最多 200 元。
```

Agent 会先确认该服务真正要求的是国家、固定地址还是其他条件。确认确实需要后，才比较“服务器加固定美国出口”这类多一层的方案，并写清多出的费用和故障点。

## Agent 最后应该给你什么

不要接受一长串产品名。Agent 应该最多给两张卡：一个推荐，一个备选。

```text
推荐方案：一句话说明适合你的原因

现在实际付款：
以后多久续费、每次多少：
折算每月：
包含哪些东西：
预计改善：
仍可能遇到：
退款和更换限制：
需要你亲自做：
官网链接和核验日期：
```

两张卡看完仍不知道怎么选，可以直接问：

> 如果用我的预算和最在意的事情替我排一次优先级，你推荐哪个？请用三句话说明。

## 付款前最后确认

Agent 必须再次检查：

1. 结账页这次实际扣多少钱，用什么币种。
2. 是按月、季度还是年度购买。
3. 以后续费多少钱，是否自动续费。
4. 购买地区有没有选错。
5. 流量、退款、换地址和取消服务有哪些限制。
6. 付款后你要从哪里找到服务器控制页面和恢复入口。

你明确说“这个价格和条件可以接受”后，再自己完成付款。
