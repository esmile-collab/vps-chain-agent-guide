# 已知客户端兼容情况

这份记录只保存实际遇到过的版本差异，方便 Agent 排障。它会随新的测试结果更新。

## v2rayN 与电视代理

最后核对日期：2026-09-08

当前项目维护者在自己使用的电视代理方案中观察到：`v2rayN 7.23.2` 可以工作，其他版本在这套具体配置中还没有确认通过。

这是一条“已知可用的回退线索”，不代表所有电视、电脑和网络都必须使用 `7.23.2`。普通电脑和手机连接也不需要因为这条记录主动降级。

### 用户怎么告诉 Agent

电视无法使用时，把下面这段发给 Agent：

```text
我的电视代理没有正常工作。这个项目记录过 v2rayN 7.23.2 在一套电视代理配置中可以使用。请先记录我当前的系统、v2rayN 版本、运行模式和故障现象，再判断是否需要用 7.23.2 做一次对照测试。不要直接覆盖现有配置，先备份并告诉我恢复方法。
```

### Agent 怎么处理

1. 先记录电脑系统、处理器、当前 v2rayN 版本、内核版本、电视如何连接电脑，以及“不能用”的具体表现。
2. 备份现有客户端目录和配置，保留当前版本，避免降级失败后无法恢复。
3. 先检查较新版本的设置差异和官方已知问题。只有现有配置仍失败时，才把 `7.23.2` 当作对照版本测试。
4. 只从 [v2rayN 7.23.2 官方发布页](https://github.com/2dust/v2rayN/releases/tag/7.23.2)下载匹配设备的文件，记录文件名、来源和校验值。这个版本在官方页面标记为预发布版。
5. 使用同一份节点配置和同一台电视对照测试，记录是否能连接、是否能正常播放，以及电脑自身网络是否受影响。
6. 测试完成后保留“版本 + 系统 + 连接方式 + 结果”。有较新版本通过同样测试时，优先迁移并更新本文。

### 旧版本的安全提醒

v2rayN 官方在 `7.24.2` 发布说明中披露：旧版本内置下载器存在严重的中间人攻击风险，并建议用户升级。因此，`7.23.2` 不能成为所有用户的长期默认版本。

如果确实需要用它做兼容测试：

- 只从 GitHub 官方发布页下载，不使用镜像、群文件或网盘包；
- 不使用旧版内置下载器下载或更新组件；
- 先让 Agent 核对文件来源和校验信息；
- 只保留完成电视代理所需的最小时间，并继续寻找较新版本或其他客户端的可用配置。

即使遵守这些动作，也不能证明旧版没有其他安全问题。若电视代理对你很重要，较稳妥的长期方案是让 Agent 在当前维护版本上复现问题，确认具体是哪个设置或内核变化造成差异。

官方依据：

- [v2rayN 7.23.2 发布页](https://github.com/2dust/v2rayN/releases/tag/7.23.2)
- [v2rayN 7.24.2 安全更新说明](https://github.com/2dust/v2rayN/releases/tag/7.24.2)
