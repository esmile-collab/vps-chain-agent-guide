# 把项目交给 Agent

这份指令适合第一次使用本项目。打开 Claude Code、Codex 或其他能操作本机终端的 Agent，完整复制下面的内容，然后按它每次提出的一个问题回答。

```text
请接手这个项目，带我从零完成自己的个人网络节点：
https://github.com/esmile-collab/vps-chain-agent-guide

我没有服务器和网络知识，也可能不知道自己需要什么。请先阅读仓库里的 README、AGENTS.md 和 vps-chain-deployer Skill，再按以下方式和我合作：

1. 先确认你能否读取这个仓库、查询当天网页、运行我电脑上的终端命令，并在购买服务器后连接它。只检查能力，先不要修改任何东西。
2. 一次只问我一个日常问题，从设备、平时用途、预算和当前最困扰的问题开始。不要先让我选择服务器、国家、线路或技术方案。我回答“不知道”时，请举例帮我判断。
3. 收集完信息后，再查询当天真正可以买到的产品。最多给我一个推荐和一个备选，写清本次实际付款、续费、平均每月成本、预计改善、仍可能遇到的问题和退款限制。
4. 注册、验证码、实名、付款、输入密码和批准高风险改动时，停下来告诉我该做什么。密码、验证码、私钥、完整连接链接和二维码都不能让我发进聊天。
5. 其余部署、客户端配置、安全检查和排障由你推进。每一步验证成功后再继续；失败时先恢复到上一次能用的状态。
6. 最后带我测试电脑、手机、电视和我的实际使用场景，并交付续费日期、已测试设备和故障恢复记录。

如果你缺少仓库读取、网页查询、本机终端或服务器连接能力，请直接说明缺少什么，并给我最少的下一步操作。现在先报告你能否接手，然后只问第一个问题。
```

## Agent 无法直接接手时

- **无法读取仓库**：让它先运行 `git clone https://github.com/esmile-collab/vps-chain-agent-guide.git`，进入目录后继续。
- **只能聊天，不能运行命令**：先让它完成需求判断和产品调研；购买后的部署换到有本机终端能力的 Agent。
- **不能查询网页**：不要用它给出的历史价格直接购买，换成能读取当天官网页面的 Agent。
- **不能连接服务器**：让它只生成执行计划，不要把服务器密码或私钥发给它。

电脑还没有合适的 Agent，按 [`get-an-agent.md`](get-an-agent.md) 安装。需要知道哪些步骤必须自己处理，见 [`human-steps.md`](human-steps.md)。
