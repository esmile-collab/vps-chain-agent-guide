# 小白只需要做这些

1. 如果还没装 Agent，先看 [`get-an-agent.md`](get-an-agent.md)，在 Mac 或 Windows 上安装 Claude Code 或 Codex CLI。
2. 告诉 Agent：你在哪、要哪个国家的出口、几台设备、每月最多花多少钱、是否需要游戏/视频会议。
3. 打开 Agent 给出的官方购买链接，核对套餐、地区、账期、续费和总价。
4. 自己注册、收验证码、同意条款和付款。密码、验证码、银行卡信息不要发给 Agent。
5. 把 Agent 需要的“服务器 IP、登录用户名、临时密码”按提示输入到本机隐藏输入框。不要把它们粘贴到聊天里。
6. Agent 部署完成后，Windows 或 Mac 使用 v2rayN；iPhone/iPad 使用 Shadowrocket 或其他官方来源客户端。
7. 让 Agent 带你做 IP、DNS、速度和手机/电脑测试。测试没过就停在当前步骤，不要自己乱改服务器。

你随时可以问 Agent：“这一步会改什么？失败怎么退回？我需要自己做什么？” Agent 应该一次只解释一个动作，并在重装、改防火墙、改 SSH、重启或开启全局代理前等你确认。
