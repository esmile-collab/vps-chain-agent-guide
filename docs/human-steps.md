# 你从开始到完成只要做这些

这份清单只写必须由你完成的动作。服务器命令、技术选择和检查交给 Agent。

## 第 1 步：在电脑上打开 Agent

需要一台 Mac 或 Windows 电脑。手机可以在最后使用节点，但不适合单独完成整套部署。

- 已经能运行 Claude Code 或 Codex：进入仓库并启动它。
- 从没装过：按 [`get-an-agent.md`](get-an-agent.md) 安装。

如果打开后只能聊天、不能读取电脑文件或运行命令，就告诉它：“先检查你有没有本地文件和终端权限。”

## 第 2 步：把 README 的启动提示发给它

你只需用自己的话回答。预算、设备、常用软件、现在最烦的问题，这些就够了。

遇到听不懂的问题，直接说：

> 我不知道这个词。请先告诉我它和价格、稳定、速度有什么关系，再举两个生活化例子。

Agent 每次应该只问一个问题。

## 第 3 步：从最多两个方案里选一个

重点只看五件事：

1. 这次银行卡实际扣多少。
2. 以后多久续费，每次多少。
3. 它更可能解决你现在的哪个问题。
4. 仍可能慢、断或不能用的地方。
5. 不满意时能否退款、更换或停用。

看不懂就不要付款。可以让 Agent 直接说：“按我的预算和最怕的问题，你推荐哪个？”

## 第 4 步：你自己注册和付款

Agent 可以给官网链接、陪你核对页面。下面这些内容只由你本人处理：

- 邮箱、手机号和账号密码；
- 验证码、实名资料和服务条款；
- 银行卡、PayPal 等支付信息；
- 最后一次付款确认。

不要把密码、验证码、银行卡信息或恢复码发给 Agent。

## 第 5 步：把购买结果告诉 Agent

付款后，在服务商官网找到服务器控制页面。你可以告诉 Agent：

- 产品已经开通；
- 购买的地区和系统；
- 服务器的公开地址和登录用户名；
- 控制页面有没有“重装”“网页终端”或“恢复”入口。

临时登录密码不要粘贴进聊天。Agent 需要时，应让你在电脑终端出现的隐藏输入框里亲自输入。

## 第 6 步：批准会影响服务器的操作

Agent 会先做不改东西的检查。遇到下面动作，它应先告诉你“会改什么、可能中断多久、失败怎么恢复”，再等你明确同意：

- 重装或删除服务器内容；
- 安装第三方软件；
- 修改登录方式或防火墙；
- 重启服务器或网络服务；
- 让客户端接管设备的全部网络。

如果这是用过的服务器，里面有网站、文件或其他服务，要立刻告诉 Agent，先停止部署并确认会不会冲突。

## 第 7 步：在自己的设备上安装客户端

Agent 会根据你的设备给官方链接和对应版本。你负责点击安装，并同意系统弹出的网络权限。

- Windows、Mac、Linux：常用 v2rayN 或 Hiddify。
- Android：常用 v2rayNG 或 Hiddify。
- iPhone、iPad：常用 Shadowrocket 或 Hiddify。

详细步骤见 [`clients.md`](clients.md)。连接信息和二维码相当于密码，只在自己的设备之间传递。

## 第 8 步：亲自试用

至少完成下面几项：

- 电脑能打开常用网页；
- 手机分别在 Wi-Fi 和移动数据下能连接；
- 显示的国家符合购买方案；
- 常用软件、视频会议或游戏按你的实际用途试一次；
- 断开客户端后，设备能恢复普通网络。

只要有一项不对，就把现象告诉 Agent，例如“电脑能用，手机流量不能用”。不要同时乱改多个开关。

## 第 9 步：保存交付记录

完成前，让 Agent 告诉你：

- 买了哪些服务、各自什么时候续费；
- 哪些设备已经测试；
- 连接信息保存在哪里；
- 节点突然不能用时先做哪三个检查；
- 服务器进不去时从哪个官网恢复入口处理。

密码和完整连接信息放在自己的密码管理器或加密存储里，不能写进公开文档或 GitHub。

安全风险和恢复办法见 [`security.md`](security.md)。
