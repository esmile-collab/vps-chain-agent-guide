# 从公共“机场”迁移到自己的网络节点

## 最快开始：把这段直接发给 Agent

已经有 Claude Code、Codex 或其他能操作本机终端的 Agent，复制下面整段即可。你可以先不看后面的长说明。

```text
请接手这个项目，带我从零完成自己的个人网络节点：
https://github.com/esmile-collab/vps-chain-agent-guide

我没有服务器和网络知识，也可能不知道自己需要什么。请先阅读仓库里的 README、AGENTS.md 和 vps-chain-deployer Skill，再按以下方式和我合作：

1. 先确认你能否读取这个仓库、运行我电脑上的终端命令，并在购买服务器后连接它。只检查能力，先不要修改任何东西。
2. 一次只问我一个日常问题，从设备、平时用途、预算和当前最困扰的问题开始。不要先让我选择服务器、国家、线路或技术方案。我回答“不知道”时，请举例帮我判断。
3. 收集完信息后，再查询当天真正可以买到的产品。最多给我一个推荐和一个备选，写清本次实际付款、续费、平均每月成本、预计改善、仍可能遇到的问题和退款限制。
4. 注册、验证码、实名、付款、输入密码和批准高风险改动时，停下来告诉我该做什么。密码、验证码、私钥、完整连接链接和二维码都不能让我发进聊天。
5. 其余部署、客户端配置、安全检查和排障由你推进。每一步验证成功后再继续；失败时先恢复到上一次能用的状态。
6. 最后带我测试电脑、手机和我的实际使用场景，并交付续费日期、已测试设备和故障恢复记录。

如果你缺少浏览网页、本机终端或服务器连接能力，请直接说明缺少什么，并给我最少的下一步操作。现在先告诉我你能否接手，然后只问第一个问题。
```

电脑还没有 Agent：打开 [`docs/get-an-agent.md`](docs/get-an-agent.md)，选 Claude Code 或 Codex 安装一个，再回来复制这段话。

下面的内容用于让你知道整个过程会发生什么。遇到不放心的步骤时再回来查，不要求一次读完。

如果你觉得现在用的公共节点经常断、速度忽快忽慢，或者想让自己的网络更稳定，这个项目会让 Agent 陪你从零做完。

你不需要先学网络知识，也不用先决定买哪家、选哪个国家、用哪种技术。你先说自己的设备、预算、平时拿网络做什么，以及最烦的是什么。Agent 会把选择缩小到最多两个，用正常人能看懂的话讲清价格、区别和风险，再一步一步带你购买、部署、安装和测试。

一句话分工：

- 你负责做决定、注册账号、付款、收验证码、输入密码和最后试用。
- Agent 负责查资料、比较方案、检查购买页面、配置服务器、生成连接信息、指导安装和排查问题。

## 先看看它能不能解决你的问题

这个项目比较适合下面这些情况：

- 你正在用公共“机场”，但经常断线、晚高峰变慢，或者客服和线路不够稳定。
- 你想自己单独使用一个节点，不想和很多陌生人共用同一套服务。
- 你有 Mac、Windows、iPhone、iPad、Android 或电视，但完全不懂服务器。
- 你愿意承担每月几十元到几百元的费用，也愿意记住续费日期。
- 某些工作或账号希望长期显示在同一个国家，但你不知道该怎么买。

它无法保证任何网站永远可用，也无法保证买到的线路一定适合你家或公司的网络。实际效果要在你的设备和网络上测试。这个项目只支持你有权管理的个人设备和账号，不用于共享售卖、公开代理、攻击或绕过平台风控。

## 这些词现在都不用懂

你可能会在网上看到 VPS、IP、线路、协议、端口、SSH、入口、出口、直连、链式代理等词。先不用研究，也不要靠猜来选。

在这个项目里，Agent 会先问生活化的问题。等某个词真的影响付款或使用时，它才解释：这个东西是什么、为什么和你有关、选错会发生什么。

你随时可以回答“我不知道”。Agent 应该继续举例帮你判断，不能把选择题丢给你自己查。

## 你可以直接这样开口

任选一句发给 Agent，也可以按自己的情况改：

> 我用 Mac 和 iPhone，每月最多 150 元，主要上网页、看视频和开视频会议。现在的公共节点晚上经常断。我完全不懂网络，请从零带我做。

> 我用 Windows 和 Android，最在意稳定，速度够用就行。我不知道该买什么，也不知道自己需不需要固定国家。

> 我有些服务希望长期显示美国，但不确定是否真的需要固定地址。请先问我几个简单问题，再给我两个以内的选择。

如果连预算也没概念，可以说：“我不知道要花多少，先告诉我最低能用、比较省心这两个档位分别大概要付多少。”

## Agent 会怎么带你做

整个过程通常是下面七步。每次只处理眼前一步：

1. **先听懂你的情况**：问设备、用途、预算和最困扰的问题。你不需要回答技术名词。
2. **查当天能买到的产品**：核对官网价格、地区、付款周期、续费和退款条件。
3. **给你最多两个选择**：直接写清“现在要付多少”“以后多久续费”“更适合解决什么”“可能哪里不理想”。
4. **陪你购买**：Agent 打开或给出官网链接并核对页面；账号注册、验证码、条款确认和付款由你完成。
5. **接手配置**：你批准后，Agent 在自己的工作目录里检查并配置你刚买的服务器。密码只在你电脑的隐藏输入框中输入。
6. **带你装到设备上**：Agent 按你的 Mac、Windows、iPhone、Android 或电视使用方式给出对应客户端和导入方法。
7. **一起验收**：检查能不能连、显示的国家是否正确、会不会漏出原网络信息、速度和断线情况是否能接受。测试不通过就继续排查。

完成后，Agent 还要交给你一份不含密码的记录：买了什么、什么时候续费、哪些设备已测试、坏了先检查哪里、怎样恢复到上一次能用的状态。

## 一个完整例子

小林只有 Mac 和 iPhone，公共节点晚高峰经常断，每月最多愿意花 150 元。他不知道“固定 IP”是什么。

Agent 不会先让小林选技术方案。它会继续问：平时是否开视频会议、有没有某个服务必须显示美国、第一次付款最多能接受多少、偶尔自己处理故障能否接受。

问完后，Agent 可能给出两张很短的方案卡：

```text
方案 A：先低成本试一个月
现在需要付：约 XX 元
以后续费：每 X 个月约 XX 元
适合：日常网页、视频，先确认你家网络连过去是否稳定
代价：线路一般，晚高峰仍可能波动

方案 B：选择离你更近、线路更好的地区
现在需要付：约 XX 元
以后续费：每 X 个月约 XX 元
适合：更在意稳定和视频会议
代价：价格更高，仍需实际测试
```

金额必须来自当天官方购买页面。很多服务按季度或按年收款，Agent 会同时写“这次实际付款”和“平均每月成本”，避免看起来便宜、付款时才发现要一次交一年。

小林只需要选 A、选 B，或者说“都太贵”。确认后 Agent 才继续，不会在他还没看懂时让他付款。

## 哪些事情一定要你自己做

只有下面几类动作 Agent 不能替你决定：

1. **注册和付款**：你自己填写邮箱、验证码、实名信息和银行卡等支付信息。
2. **输入秘密**：密码和验证码只在供应商网页或你电脑的隐藏输入框中输入，不能发进聊天。
3. **批准有影响的改动**：重装服务器、修改登录方式、改变防火墙、重启服务、让客户端接管设备网络前，Agent 会告诉你影响和恢复方法，等你明确同意。
4. **安装和最后试用**：你从官方来源安装客户端，并亲自在常用 Wi-Fi、手机流量和常用软件里测试。

其他技术步骤都应该由 Agent 完成。看不懂时直接说“用更简单的话解释这一步”，不用自己搜索一堆教程。

## 大概需要多少钱

下面只能帮助你建立价格感觉，不能当成当天报价：

- **先低成本试用**：通常只买一台海外小服务器，常见参考是每月 3–15 美元。
- **更在意从国内连过去的稳定性**：会优先比较日本等亚洲地区，常见参考是每月 10–35 美元。
- **希望长期显示某个国家**：可能还要购买一个固定的当地网络出口，常见参考是在服务器之外每月再加 3–20 美元。
- **工作不能轻易中断**：可能再准备一个备用节点，费用也会增加一份。

不同供应商会按月、季度或年度收费，库存和续费价也会变。先告诉 Agent 你“平均每月最多花多少”和“第一次最多能付多少”，它会按当天结账页面重算。供应商入口见 [`docs/providers.md`](docs/providers.md)，也可以把 [DIGVPS 测评索引](https://digvps.com/review) 当作发现候选的参考；最终价格和条款仍以供应商官网为准。

## 安全问题，先记住四句话

- 服务器密码、验证码和付款信息只由你本人输入。
- Agent 生成的连接链接和二维码相当于家门钥匙，不能发群、传网盘或提交到 GitHub。
- Agent 每次做可能让服务器断开的改动前，都要告诉你怎么恢复。
- 怀疑密码或连接信息泄露时，先停用旧信息并重新生成，再继续使用。

更完整的风险说明和兜底方法见 [`docs/security.md`](docs/security.md)。
