# 方案选择器（Agent 内部参考）

## 先收集的变量

一次只问一个问题：用户所在地区和 ISP；目标国家；是否要求固定 IP；设备和并发数；是否需要 UDP/QUIC；每月流量；预算上限和账期偏好；是否愿意维护一台或两台服务器；是否接受重装和多一层故障。

把“速度、稳定、固定国家 IP、低维护、低成本”让用户选出优先级。不要替用户填答案。

## 路由决策

| 条件 | 推荐 | 说明 |
| --- | --- | --- |
| 主要目标是低成本和少故障 | 一台 VPS 直连 | 先实测入口到目标站点；出口为机房 IP |
| 入口线路可用，但必须长期显示某国 IP | 入口 VPS + 固定认证 SOCKS5/ISP | 先单独验证出口，再接入；链路瓶颈取两段较差者 |
| 不想依赖代理供应商 | 入口 VPS + 出口 VPS | 两台均由用户控制，维护和成本翻倍 |
| 不能接受单点故障 | 两个入口配置，第二台按需启用 | 备份节点也要定期登录和测试 |
| 只有特定网站需要目标国 IP | 分流 | 其余流量走直连，降低成本和延迟 |
| 需要 UDP/游戏/会议 | 直连或支持 UDP 的出口 | 购买前确认 SOCKS5 的 UDP 能力，部署后单独验收 |

低价 VPS 适合验证需求，不保证中国方向线路。固定 ISP/住宅产品适合稳定出口 IP，不等于无限带宽或所有平台都接受。平台限制、当地法律和供应商条款始终优先。

## 推荐输出格式

给用户一段短结论：

```text
主方案：<拓扑>，预计月均 <金额区间>，原因：<两点>。
回退方案：<拓扑>，代价：<一项>。
付款前我会核对：<地区/账期/流量/续费/退款/协议能力>。
你需要亲自完成：注册、付款、验证码、密码输入和最终设备测试。
```

只有用户确认主方案后，才进入供应商购买和服务器变更。
