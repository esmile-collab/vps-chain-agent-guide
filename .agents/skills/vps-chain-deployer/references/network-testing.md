# 网络质量验收（Agent 内部参考）

## 测试顺序

1. VPS：SSH、端口、Xray 服务和重启恢复。
2. 直连入口：客户端连接后，用 IPinfo 确认出口是 VPS。
3. 出口账户：从 VPS 单独测试 SOCKS5，确认认证、国家和 ASN。
4. 链路：启用出口后，用两个独立 IP 查询确认最终出口。
5. 泄露：BrowserLeaks IP/DNS/WebRTC、DNSLeakTest，检查 IPv4、IPv6、DNS 和 WebRTC。
6. 体验：Speedtest 同设备同时间比较；服务器用 `mtr -rwzc 100 <用户指定目标>` 看中位延迟、抖动和丢包。
7. 应用：需要游戏、语音、会议时单独测试 UDP/QUIC；不能从 TCP 测试推断 UDP 可用。

## 结果解释

- 国家和 ASN 不符合购买目标：先核对供应商交付，再决定退款或更换，不要先改 Xray。
- 两次立即检查相同不代表长期固定；数小时到数日复查才可记录“暂时固定”。
- 延迟、丢包和速度没有适用于所有人的统一阈值。先让用户说出最低要求，再以同一目标做对比。
- 链式速度由入口到出口、出口到目标两段中较差的一段决定。
- 全局代理下暴露家庭 DNS、IPv6 或 WebRTC 地址，说明客户端或系统仍有直连路径。
- IP 检测通过不代表某个平台一定接受；遵守平台条款，不通过频繁换 IP 绕过限制。

记录测试时间、客户端、拓扑、入口和出口的打码标识、IP/ASN/国家结果、延迟/丢包/速度、DNS/IPv6/WebRTC 结果，以及未测试的 UDP 或应用。不要记录完整链接、密码或私钥。
